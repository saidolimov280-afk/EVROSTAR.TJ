# Боти EVROSTAR дар Telegram — мағоза дар дохили Telegram

Мизоҷ ботро мекушояд → тугмаи **«🛒 Мағоза»**-ро пахш мекунад → худи сайти evrostarshop.com
(каталог, сабад, ҳисобкунак, фармоиш) дар дохили Telegram кушода мешавад. Сервер лозим нест.

Сайт дар дохили Telegram худаш мефаҳмад, ки дар Telegram аст (`?tg=1` ва маълумоти Telegram дар суроға):
- экранро пурра мекушояд, рангҳои мағоза;
- тугмаи «Ақиб»-и Telegram аввал равзанаи кушодаро мепӯшонад, баъд ба саҳифаи қаблӣ мебарад;
- WhatsApp ва дигар сайтҳо берун аз Telegram кушода мешаванд (фармоиш ба WhatsApp мерасад);
- пешниҳоди «барномаро насб кунед» пинҳон аст.
Фармоишҳо мисли пештар дар admin сабт мешаванд ва Telegram-боти соҳиб хабар медиҳад.

> Ин боти **нав** барои мизоҷон аст. Боти хусусии шумо (хабари фармоишҳо ва ҳисобот) ҳамон тавр мемонад.

## Қадамҳо (дар Telegram, бо @BotFather)

### 1. Сохтани бот
`/newbot` → ном:
```
EVROSTAR — панелҳои офтобӣ
```
→ username (бояд бо `bot` анҷом ёбад), масалан `evrostar001_bot` (агар банд бошад: `evrostar_tj_bot`, `evrostarshop_bot`).

### 2. Тавсиф (пеш аз «Start» намоён аст)
`/setdescription` → ботро интихоб кунед → матн:
```
☀️ EVROSTAR — панелҳои офтобӣ, инверторҳои гибридӣ, аккумуляторҳо, камераҳо ва роутерҳо.

🛒 Тугмаи «Мағоза»-ро пахш кунед: каталог, нархҳо, ҳисобкунаки системаи офтобӣ ва фармоиш — дар дохили Telegram.

📍 Ҳисор, Бозори Калони Ҳисор
🚚 Расонидан ба тамоми Тоҷикистон
📞 WhatsApp: +992 405 555 530

Солнечные панели, инверторы и АКБ. Нажмите «Мағоза» — каталог и заказ прямо в Telegram.
```

### 3. «Дар бораи бот» (дар профил)
`/setabouttext` → матн:
```
Панелҳои офтобӣ, инверторҳо, аккумуляторҳо ва камераҳо. Ҳисор, Бозори Калон. WhatsApp +992 405 555 530
```

### 4. Расми бот
`/setuserpic` → ботро интихоб кунед → расми [`bot-avatar-640.png`](bot-avatar-640.png)-ро ҳамчун **акс** фиристед.

### 5. Тугмаи «Мағоза»
`/mybots` → бот → **Bot Settings** → **Menu Button** → **Configure menu button** →
линк:
```
https://evrostarshop.com/?tg=1
```
→ номи тугма:
```
🛒 Мағоза
```

### 6. Тугмаи «Open App» дар профили бот (тавсия)
`/mybots` → бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → ҳамон линк:
```
https://evrostarshop.com/?tg=1
```
Баъд мағоза аз профили бот ва рӯйхати чатҳо ҳам кушода мешавад.

### 7. Санҷиш ва паҳн кардан
- Ботро кушоед → «🛒 Мағоза» → молро ба сабад гузоред → фармоиш → бояд WhatsApp кушода шавад.
- Линки бот барои Instagram, WhatsApp ва визиткаҳо: `https://t.me/<username>`.

## Донистан муҳим
- Бот ба паёмҳо худкор ҷавоб намедиҳад (барои ин сервери доимӣ лозим аст). Мизоҷ ҳама корро бо тугмаи «Мағоза» мекунад.
- Ҳар тағйир дар сайт дарҳол дар Telegram ҳам пайдо мешавад — ботро аз нав танзим кардан лозим нест.
- Код: скрипти Telegram дар `index.html` (дар боло, `evroInTelegram`, `evroOpenExternal`); тест: `test_telegram_mini_app` дар `tests/e2e/test_app.py`.
