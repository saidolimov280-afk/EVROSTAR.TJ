# EVROSTAR Android
Android WebView app for https://evrostarshop.com/. Requires Android 8.0+ and internet.
Build: Gradle 8.11.1, Android Gradle Plugin 8.9.2, JDK 17, SDK 35.
Actions builds only unsigned APKs with read-only repository permissions. No signing credentials are committed or uploaded to Actions.
Sign the unsigned APK privately with apksigner, keep the signing identity in a private backup, then distribute the signed APK.
